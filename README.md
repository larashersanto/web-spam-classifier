# Web Klasifikasi Spam SMS

Aplikasi web sederhana untuk mengklasifikasikan pesan teks (SMS) ke dalam kategori **Ham (Normal)** atau **Spam**. Model ini dibangun menggunakan algoritma Machine Learning dan di-*deploy* menggunakan Streamlit.

## Fitur
- Deteksi spam *real-time* berbasis teks.
- Menggunakan model klasifikasi dengan *threshold* optimal (0.2800) untuk meminimalkan *False Negative*.
- Antarmuka ramah pengguna dengan Streamlit.
